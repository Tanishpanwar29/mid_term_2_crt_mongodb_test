 5. List students whose overall marks are 75 or more

javascript

```javascript
db.students.find({
    marks: { $gte: 75 }
})
```

 6. List students belonging to either CSE or IT department

javascript

```javascript
db.students.find({
    dept: { $in: ["CSE", "IT"] }
})
```

 7. Find students who scored more than 80 in DBMS

javascript

```javascript
db.students.find({
    scores: {
        $elemMatch: {
            subject: "DBMS",
            mark: { $gt: 80 }
        }
    }
})
```

8. Display top 3 students, highest marks first, hide \_id

javascript

```javascript
db.students.find(
    {},
    {
        _id: 0,
        name: 1,
        marks: 1
    }
).sort({ marks: -1 }).limit(3)
```
